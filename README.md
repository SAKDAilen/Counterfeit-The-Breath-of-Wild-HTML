# 旷野之息 · 海拉鲁冒险 v9 / Breath of the Wild — Hyrule Adventure

一个用 Three.js 从零程序化生成的《塞尔达传说：旷野之息》风格开放世界 Web 游戏。所有地形、角色、建筑、道具与特效都由数学几何体与着色器生成，不加载任何外部贴图、模型或音频文件。
  
A procedurally generated Breath of the Wild-inspired open-world Web game built with Three.js. No external textures, models, or audio files are loaded.

> 这是一个非官方的同人技术演示，与任天堂无关。所有地形、角色、建筑、道具均由代码生成。
>   
> Unofficial fan-made technical demo. Not affiliated with Nintendo. Everything is generated procedurally.

## 运行

### 方式一：后台 + 浏览器（推荐，支持云存档）

Windows 下双击 **`play.bat`**：自动启动后台并打开 `http://127.0.0.1:8787/`。

或手动：

```bat
:: 双击 start-server.bat，或：
start-server.bat
:: 然后打开 http://127.0.0.1:8787/
```

无需 `npm install`，后台仅使用 Node.js 内置模块。若电脑已安装 Node.js 20+，`npm start` 也可用。

### 方式二：直接打开 `main.html`

直接双击 `main.html` 即可运行（three.js 从 CDN 加载）；此模式没有云存档/排行榜，但单机功能完整。
  
若没有网络，游戏会尝试加载本地 `assets/three.module.js`（通过 http 打开时）。

### 测试

```bat
:: 后台 25 项接口测试
node server\test.js

:: 前端模块语法检查
python tools\check_js.py
```

## 项目结构

```
main.html                 游戏前端（Three.js 场景 + 1024 关节角色 + 全部玩法）
index.html                静态托管首页（自动跳转到 main.html）
assets/three.module.js    本地 three.js r160（离线兜底）
js/physics.js             v9 零依赖刚体物理引擎（固定步长、冲量求解、休眠）
js/adventure.js           v9 冒险日志数据（全部 120 神庙名称 / 挑战 / 首领）
js/api.js                 前端 API 客户端（云存档、排行榜、i18n、在线探测）
locales/
  i18n.js                 内嵌四语言词典 + 运行时（经典脚本，file:// 可用）
  zh-CN.json …            后台 / 外部调用用的平面词典
server/
  index.js                HTTP 服务、静态托管、REST API、CORS/gzip/ETag/限流
  store.js                JSON 原子持久化、损坏文件隔离
  test.js                 25 项集成测试
data/                     运行时云存档、档案、排行榜（自动创建）
docs/SERVER.md            后台 API 文档（中英）
start-server.bat          启动后台（优先 PATH 中的 node，否则用随附运行时）
play.bat                  一键启动后台并打开浏览器
tools/                    开发与测试脚本（截图、语法检查、构建语言包）
```

## 性能说明

- 草地（约 1.3 万丛）、花、灌木、树木、岩石、云、鸟群均使用 `InstancedMesh`；建筑、神庙、神兽静部件按材质合并。
- v9 场景约 **1,000 draw calls / 120 万三角形（含阴影）**。无头 SwiftShader 软件渲染只有约 **2 FPS**，桌面 GPU 通常远高于此；该测试受软件渲染限制，仅作相对参考。
- **F2** 切换四档画质；自动档会根据 FPS 在 高 → 中 → 低 之间自适应，并调整 `devicePixelRatio`、阴影、草地和云。
- 怪物、可拾取道具、NPC 使用距离剔除；阴影贴图 2048，每两帧更新一次。
- 小地图与全地图使用 `384 × 308` 高度/颜色缓存，避免每帧重新计算 `terrainHeight`。
- 物理使用固定时间步长与子步进；`U` 或自动检测会把角色推离卡住的模型。

## 已知限制（请阅读）

- 这是程序化同人技术演示，不是逐像素、逐任务的原作复刻；地图比例、建筑布局与部分怪物出生点经过重组，无法与原版 1:1 对应。
- 120 座神庙以「世界中的 11 座实体神庙 + 日志中的 136 条试炼档案/投影试炼」实现，不是 136 个独立室内 3D 关卡。
- 四神兽与最终首领使用程序化几何体与脚本化阶段，不是官方模型或完整原作演出。英杰之诗、剑之试炼、大师摩托 Zero 为可玩的简化版剧情链。
- 部分支线与挑战以进度条件/日志条目呈现；并非原作 76 条支线的完整对话树。
- 新加入的中文 UI 尚未全部补齐四语言翻译；原有界面与任务文本仍可通过 `L` 切换。
- 单机为主；后台提供云存档与排行榜，不含多人同步。
- 不同显卡/浏览器帧率差异较大，建议 Chrome / Edge 最新版全屏；卡顿时按 **F2 → 中/低**。
